# Tự tính bằng tay

Cách này tự tính mean, median và độ lệch chuẩn bằng `sum`, `sorted` và `math.sqrt`. Nó chạy đúng và cho bạn thấy `statistics` đã làm gì giúp bạn. Nhưng code dài hơn, dễ sai hơn (thử median với số phần tử chẵn xem!) và khó đọc hơn, nên trong code thật hãy ưu tiên hàm đã được kiểm thử của thư viện chuẩn.
