Hãy tự viết hai hàm hoàn chỉnh. Đặt code bên trong mỗi hàm và `return` kết quả.

1. `bmi(weight_kg, height_m)` trả về chỉ số BMI: cân nặng chia cho bình phương chiều cao. Ví dụ `bmi(80, 2.0)` là `20.0`.
2. `bmi_category(bmi_value)` trả về nhãn phân loại:
   - dưới `18.5`: `"underweight"`
   - từ `18.5` đến dưới `25`: `"normal"`
   - từ `25` đến dưới `30`: `"overweight"`
   - từ `30` trở lên: `"obese"`

Nhớ: `return` giá trị, đừng `print`. Bấm **Kiểm tra** để chạy test.
