`passed(scores, threshold)` takes a dict of `name -> score` and returns a **sorted list of the names** whose score is **at least** `threshold`.

```python
passed({"Minh": 8, "Lan": 5, "Hoa": 3}, 5)  # ['Lan', 'Minh']
```
