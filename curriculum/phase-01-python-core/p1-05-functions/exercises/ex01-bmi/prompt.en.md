Write two whole functions yourself. Put your code inside each function and `return` the answer.

1. `bmi(weight_kg, height_m)` returns the body-mass index: weight divided by height squared. For example `bmi(80, 2.0)` is `20.0`.
2. `bmi_category(bmi_value)` returns a label:
   - below `18.5`: `"underweight"`
   - from `18.5` up to (not including) `25`: `"normal"`
   - from `25` up to (not including) `30`: `"overweight"`
   - `30` or more: `"obese"`

Remember: `return` the value, do not `print` it. Press **Check** to run the tests.
