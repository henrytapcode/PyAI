Write `sum_of_evens(n)`: it returns the sum of all **even** numbers from `1` to `n` (including `n`).

Examples: `sum_of_evens(10)` is `2 + 4 + 6 + 8 + 10 = 30`; `sum_of_evens(1)` is `0`; `sum_of_evens(0)` is `0`.

> Functions come properly in lesson 5. For now: write your code **inside the function** (indented under the `def` line) and finish with `return` followed by the answer.

Press **Check** to run the tests.

**Example**

| Call | Returns |
|---|---|
| `sum_of_evens(10)` | `30` |
| `sum_of_evens(7)` | `12` |
| `sum_of_evens(1)` | `0` |

**Rules**
- Include `n` itself when `n` is even.
- Return a whole number (`int`).
