Viết hàm `word_count(words)`. Hàm nhận một list các từ và trả về một dict ánh xạ mỗi từ với số lần nó xuất hiện.

```python
word_count(["ai", "is", "fun", "ai"])  # {'ai': 2, 'is': 1, 'fun': 1}
word_count([])                          # {}
```
