# Regular expressions

The `re` module finds patterns in text. `\s+` means "one or more whitespace characters", and `https?://\S+` means "`http` with an optional `s`, then `://`, then any non-space characters", so `re.sub` can replace the whole link in one call. The result is the same as the main solution for the tested inputs. Regular expressions are a preview of a later topic: they are powerful and compact, but harder to read and easy to get subtly wrong. For simple jobs like these, `split` and `startswith` are clearer; reach for `re` when the pattern is more complicated than "words that start with".
