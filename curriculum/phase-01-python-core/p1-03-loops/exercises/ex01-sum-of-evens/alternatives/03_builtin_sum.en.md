# Preview: the built-in sum()

**Preview, not needed yet.** Python has a built-in function `sum()` that adds up all the numbers it is given, so `sum(range(2, n + 1, 2))` does the whole accumulator loop in one line. It is handy once you know it, but writing the loop yourself is the point of this lesson: you will need the same pattern whenever the job is more complicated than "add everything".
